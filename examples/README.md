# 完全虚构的宏观分析示例

本目录用于学习数据清洗、同口径同比计算和研究可复现性。**所有 CSV 数字均为教学虚构数据，包括未来的 2026-12 数据，不代表任何真实国家、银行或央行统计。**

## 运行

Python 3.10+，无需 pip 安装依赖，工作目录为仓库根目录：

```bash
python examples/analyse_macro.py
python examples/analyse_macro.py --baseline 2025-12 --current 2026-12
python -m unittest discover -s tests -v
```

示例输出：社融存量同比 6.00%，M2 存量同比 6.00%，CPI 指数同期变化 1.49%，二者存量增速差 0.00 个百分点。所有比率均为从固定样本计算得到的教学值。

## CSV 字段

| 字段 | 单位 | 含义 | 有效条件 |
|---|---|---|---|
| `date` | `YYYY-MM` | 假设数据观察月份，唯一且升序 | 有效年月 |
| `tsf_stock` | 假设万亿元 | 假设社融期末存量 | 必须大于 0 |
| `m2_stock` | 假设万亿元 | 假设广义货币存量 | 必须大于 0 |
| `cpi_index` | 指数点 | 假设消费价格指数 | 必须大于 0 |
| `policy_rate` | 百分数 | 假设政策利率，仅供说明 | 有限数值，可为负 |

程序拒绝重复月份、非升序日期、缺失比较月份、非同月同比和非有效输入。真实经济数据的口径问题仍需人工核验。使用公开数据时，请保留系列 ID、发布版本、季节调整、缺失值策略以及最终来源链接。

## 章节计算器公式（money_math.py）

第 01–28 章的交互计算器使用与页面相同的确定性算术。`examples/money_math.py` 用纯标准库函数复现这些公式，并把每个函数的默认值打印出来，便于离线核对页面上的数字：

```bash
python examples/money_math.py
```

覆盖的公式包括费雪精确与实际利率、回购 ACT/365 利息、债券现金流折现价、简化货币乘数、线性货币需求、IS–LM 均衡、价格指数变化、通缩下的实际债务负担、杠杆放大权益损失、同比增速、简化泰勒规则、预期损失 PD×LGD×EAD、稳定币压力后储备覆盖率和抛补利率平价远期汇率。全部数字为教学算术，不是真实货币、市场或预测数据；输入不合法时函数抛出 `ValueError`。`tests/test_money_math.py` 同时断言这些函数的结果与各章页面静态显示的默认值一致。
