# Evidence ledgers

Each `chapter-NN.json` maps material factual or quantitative claims to a source and a locator.

- `verified`: supported by the linked source at the stated locator.
- `derived`: a synthesis of established mechanisms; the notes explain the inference.
- `illustrative`: a teaching example or hypothetical scenario, not an empirical claim.
- `unverified`: not cleared for publication; should be removed or explicitly qualified.

A source link is not proof by itself. Editors must check that the source supports the precise wording, date, jurisdiction and statistical definition used in the article.
