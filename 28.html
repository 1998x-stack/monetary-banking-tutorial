货币银行学 · 第 28 章

如何完成一份可复盘的宏观货币政策研究？

将宏观数据、政策阅读、金融传导与风险情景结合为一份可独立检查的报告，附带不依赖网络的 Python 示例、样本数据和自动化测试。

综合项目可复现计算含情景互动

“货币政策会影响什么？”是一个机制问题；“在下个季度实际会发生什么？”则是一个有信息集和预测误差的问题。完整的研究流程既要解释机制，也要能复算数据、区分真实统计与假设情景，并允许结论在新的证据出现时被推翻。下面用一份完整的模拟研究演示如何完成这项工作。

把研究问题写成能够被反驳的句子

一份宏观政策研判报告必须回答一个明确问题。例如：“在给定的经济增长与通胀情景下，银行融资条件在未来两季度可能怎样变化？”这是条件性分析题；“下一次央行一定降息多少”则要求未经证实的精确预言。

研究范围应固定为某一经济体、某个数据截止日和预测期。主要问题包含三个层次：当前状态（经济数据说明什么）、政策反应（政策工具如何影响金融条件）、风险情景（哪些数据会使基本判断失效）。

以下给出一套可以独立运行的完全假设数据与研究流程。样本时间包含 2026 年 12 月，这只是未来虚构数据，用于展示年度可比数据如何计算；它不代表尚未公布的真实经济数据。

第一步：定义指标、统计期与来源

观察真实经济时，选择少量但覆盖不同机制的指标：实际产出或工业生产、通胀指标、信用或社会融资存量、银行或债券融资利率、失业 / 就业、财政融资和外部金融条件。每个指标必须记录发布时间、观察期、单位、季调、统计口径与修订版本。

中国的社融存量与 M2 不能当作同一变量。社融主要衡量金融体系向实体经济提供的融资存量，M2 则是货币统计口径下公众持有的广义货币。即使两者增速一致，也不说明借贷市场自动出清。

虚构指标2025-122026-12（假设）解释
社融存量（万亿元）400424同比 +6.00%
M2（万亿元）300318同比 +6.00%
CPI 价格指数101.0102.5期间价格指数累计约 +1.49%
假设政策利率（%）1.81.6仅为教学输入，不能据此推断实际央行操作

本示例的 CSV 位于 examples/sample_macro_data.csv；无需第三方依赖的 Python 分析程序位于 examples/analyse_macro.py。字段词典和运行方法见 examples/README.md。

第二步：从数据到机制，不跳过中间环节

使用四段推理链：宏观数据 → 货币政策反应 → 金融市场价格和信用条件 → 实体支出、就业与通胀。每一步都要提出可以被观察的指标。例如：政策利率下降，如果债券收益率不降、信用利差扩大，企业实际融资条件未必改善。

信用周期预警需要多个指标。BIS 使用信贷／GDP 缺口研究金融体系潜在压力，但明确提醒统计趋势和国别口径会改变结果。[3] 因此，不能从虚构样本中随意计算“真实经济危机概率”。

第三步：建立基准、情景和反证

基准情景应是现有数据支持下最简单、最可解释的路径。风险情景可以改变需求、供给成本、融资利差或外部利率，但每个情景必须保持自洽：供给冲击可能同时提高价格压力并压低实际活动；需求走弱可能抑制通胀，也可能因风险偏好下降使银行信用利差扩大。

情景假设变化首先验证不应直接断言
基准需求与成本大致沿现有趋势企业订单、通胀、信用利差与货币市场利率经济一定保持某一精确增长率
需求疲弱订单和投资意愿下行就业、企业贷款、财政支出与预期政策宽松必然推动股价上涨
供给冲击能源、运输或关键投入成本上升核心与总体通胀差异、利润率和供应链央行一定单方向大幅加息
金融压力风险溢价上升、短期融资收紧融资利差、银行流动性和抵押品折扣所有企业信贷同幅收缩

预测报告可参考 IMF WEO 的当前与历史版本比较预期修订，也可参考 OECD 领先指标观察转折风险，但这两者不能替代对本经济体数据和机构制度的解释。[1][2]

第四步：执行离线分析并记录可复制结果

下载仓库后，在仓库根目录运行以下代码。程序只使用 Python 标准库，读取 CSV 中的虚构数据；不访问网络，不修改官方数据：

python examples/analyse_macro.py
python -m unittest discover -s tests -v

默认比较 2025-12 与 2026-12，计算社融、M2 和 CPI 指数的期间同比变化。示例输出预期为：社融存量同比 6.00%、M2 同比 6.00%、CPI 指数同期变化约 1.49%，社融与 M2 增速差为 0.00 个百分点。差值描述的是两个不同统计指标的相对增速，不构成货币供需缺口。

要换成真实数据，必须先核对日期、货币单位、价格指数频率、数据缺失与系列修订。程序拒绝重复日期、非正数的存量与价格指数、缺失比较期和非同月的错误“同比”比较。程序能保证算术操作可复现，但不能自动保证数据经济含义正确。

第五步：形成完整的政策研究报告

一份独立交付的研究报告可以采用下列结构，每个部分都有确定的材料与反证要求：

模块必须交付的内容验收问题
摘要与截至日期研究对象、统计期、3 条结论、核心不确定性结论是否有直接证据？
数据审计指标字典、原始来源、表格和修订记录读者能否重算每个数字？
机制模型货币、融资、利率和实体需求之间的链条有没有把相关性误当成因果？
政策情景至少基准与两种风险情景、对应触发条件每种情景可否被证伪？
市场影响利率、银行信贷、汇率和资产估值的条件性传导是否考虑风险溢价和时滞？
复盘计划下一次数据发布、预测误差和需要更新的假设未来能否检验而不是事后重写？

可参考美联储 SEP 指南对预测范围和不确定性的表达方式。每个结果都应有条件限制，而不是用单一“目标价”或“确定的政策路径”替代分析。[5]

交互练习：政策传导的情景诊断

选择一组宏观冲击

以下仅提供机制上的情景检查清单，不输出证券买卖建议或真实经济预测。

基准情景：先核对实际产出、通胀趋势、银行贷款定价和风险溢价；不要仅凭政策利率推断资产价格。

验收标准：什么时候一份宏观分析算完成？

  1. 能明确引用原始统计表，并复算至少三个核心数值。
  2. 能说明流量、存量、同比、环比、名义与实际的区别。
  3. 至少写出一条政策传导路径、一个可能阻塞的机制和相应可观测指标。
  4. 至少设置基准与两种竞争性情景，说明能推翻判断的新证据。
  5. 记录“预测发布日期—目标期—实际值—误差—解释”，不能只记录成功预测。
  6. 结论不超出证据范围：不捏造央行内部意图、不把模拟收益当真实业绩，不提供脱离个人条件的确定性资产配置处方。

遵循这些标准，简短的研究也可以经得起复盘；反之，即使图表很多、语言复杂，也可能只是无法检验的市场叙事。

带走的核心方法

  • 金融分析不是猜政策，而是对统计口径、金融机制和不确定性做有证据的解释。
  • 数据审计先于建模；模型能否复制结果与预测是否准确是两个独立问题。
  • 用情景和反证把观点转成可以被挑战的判断。
  • 最终评价指标是可复核的证据链与持续的预测误差记录，而非一次性的新闻解读。

Worked reasoning

算一遍：可复现的数字，为什么仍然不等于真实的政策预测？

本项目 CSV 是完全虚构的数据，特意包含本报告编写时尚未到来的 2026 年 12 月。其中社融存量由 400 变成 424，计算结果为 6.00%；M2 从 300 变 318，也是 6.00%；CPI 指数从 101.0 变为 102.5，则同期指数变化为 (102.5÷101.0−1)×100%≈1.49%。这些数字在脚本运行中保持不变，只能说明算术可复制。

真正的宏观预测还需要记录：预测当天可见哪些官方统计、统计观察期和发布日期、训练与留出样本边界、基准预测、事后公布值与修订、平均误差和推翻假设的证据。数据可复现是工程属性，预测有效是需要未来数据检验的经验属性；不要把二者混为一谈。

教学例子的金额、日期和变量并非真实钱包、证券、央行数据或投资建议。
